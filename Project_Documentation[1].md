# Portfolio Website — Project Documentation

## 1. Introduction
This project is a personal portfolio website for Karanam Suhas, a second-year B.Tech CSE-AIML student at Sandip University. It presents education, technical skills, academic project work, and contact details.

## 2. Problem Statement
Students need a simple online space to present their skills and projects to faculty, recruiters, and collaborators.

## 3. Objectives
- Build a responsive personal portfolio.
- Present genuine skills and project work.
- Provide links to professional profiles.
- Make the resume available for download.
- Practice HTML, CSS, JavaScript, GitHub, and deployment.

## 4. Proposed Solution
A single-page portfolio with navigation links to each section. The layout uses a white and maroon color scheme, cards for skills and projects, project filters, and a contact form that opens an email draft.

## 5. Technologies Used
- HTML5 for page structure.
- CSS3 for styling and responsive layout.
- JavaScript for mobile navigation, project filtering, and email-draft behavior.

## 6. System Requirements
- Computer or mobile device with a modern browser.
- Code editor such as Visual Studio Code for editing.
- Internet connection for external profile and project links.

## 7. Features
- Home and About sections.
- Skills grouped by type.
- Three project summaries.
- Education, achievements, and experience sections.
- Resume download link.
- Email, LinkedIn, and GitHub links.
- Responsive navigation and project category filters.

## 8. Project Structure
- `index.html`: HTML, CSS, and JavaScript for the website.
- `Suhas_Karanam_Student_Resume.pdf`: downloadable resume.
- `README.md`: project setup and overview.

## 9. UI/UX Design
The website uses a white background with maroon accents, readable typography, cards, clear section headings, and a mobile-friendly navigation menu. No profile photo is used.

## 10. Implementation
The HTML defines the sections, CSS provides the layout and responsive breakpoints, and JavaScript handles the mobile menu, project filters, current year, and contact email draft.
