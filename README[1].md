# Karanam Suhas — Student Portfolio

A responsive student portfolio built with HTML, CSS, and JavaScript.

## Features
- Responsive navigation
- About, skills, projects, education, achievements, experience, resume, and contact sections
- Project category filtering
- Contact form that opens an email draft (no backend)
- Downloadable resume PDF

## Technologies
- HTML5
- CSS3
- JavaScript

## Run locally
1. Download or clone this repository.
2. Keep `index.html` and `Suhas_Karanam_Student_Resume.pdf` in the same folder.
3. Open `index.html` in a browser, or use VS Code Live Server.

## Project structure
- `index.html` — complete portfolio website
- `Suhas_Karanam_Student_Resume.pdf` — student resume
